# Лабораторная работа №2

Группа 13, вариант 9.

## Задание 1

Программа 1 находит файл с наибольшим количеством строк
и перемещает его в /var/result/data.txt.

Программа 2 находит максимальное целое число,
вычисляет его квадрат и сохраняет результат
в /var/result/result.txt.

## Запуск

docker compose up --build

Ожидаемый результат на тестовых данных: 144.

Внимание: первая программа перемещает входной файл.
Перед повторным запуском нужно восстановить тестовые данные.
